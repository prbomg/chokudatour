# Настройка секретов

Скопируйте `config.local.php.example` в `config.local.php` на сервере и заполните значения. Файл исключён из Git и не должен попадать в репозиторий. Вместо файла можно задать одноимённые переменные окружения.

Обязательные параметры: `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`. Для почтового cron также нужны `CRON_TOKEN` (случайная строка не короче 32 байт) и `ADMIN_EMAIL`.

После обновления необходимо сменить пароль пользователя базы данных у хостинг-провайдера и записать новый пароль в серверную конфигурацию. Если токен Telegram-бота когда-либо находился в репозитории, перевыпустите его через BotFather и сохраните новый токен в разделе настроек CRM.

Параметры `INITIAL_ADMIN_*` используются только при пустой таблице пользователей. Для действующей установки оставьте их пустыми.
